# Spark Challenge 2026: project docs

**Goal:** win the Monterrey Launchpad (Nov 7) with a working AI MVP for neurodivergent students, built with our Challenge Partner **Surfeando la Neurodiversidad** (Tec de Monterrey).

**Start here:**
- [16_current_state.md](16_current_state.md): what works today, how it was checked, what is open.
- [../submission/README.md](../submission/README.md): deliverables, blockers and the code-review checklist.
- [11_code_walkthrough.md](11_code_walkthrough.md): every team member reads this and reviews their modules.

## One-liner

> **Clara turns ambiguous course instructions into clear, checkable steps for autistic and ADHD university students. When something is missing, it asks instead of guessing.**
